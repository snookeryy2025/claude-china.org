**最新版本。** 发布日期 2026 年 11 月 9 日.

适用于高要求推理和长周期智能体任务

模型 ID: `claude-fable-5-2`

上下文窗口: 1M tokens · 最大输出: 128K tokens · 输入价格: $8 / MTok · 输出价格: $40 / MTok

[发布公告](https://www.anthropic.com/claude-fable-and-mythos-5-2) · [新增功能](/docs/models/fable-5-2/whats-new-fable-5-2) · [迁移指南](/docs/models/fable-5-2/migration-guide)

## 概述

Claude Fable 5.2 专为高要求的推理和长周期的智能体工作而打造。典型用途包括持续数小时的智能体会话、多步骤深度研究，以及一直推进到生成完整文档、电子表格或演示文稿的分析工作。

## Claude Fable 5.2 与 Claude Mythos 5.2

[Claude Mythos 5.2](/docs/models/mythos-5-2/overview) 提供相同的能力，但仅面向通过 Anthropic 验证计划（例如 [Cyber Verification Program](https://support.claude.com/en/articles/14604842)）验证的组织。它与 Claude Fable 5.2 具有相同的规格和定价。如需申请访问权限，请申请适用于您用例的计划，或联系您的客户团队。

| [Claude Haiku 5.5](/docs/models/haiku-5-5/overview)   | 1M      | 128K       | 起价 $0.10 / $0.50 | 最快  | 自适应             | `medium`       | 2026 年 6 月         |

* **上下文:** 在当前分词器（随 Claude Opus 4.7 引入）中，100 万令牌约相当于 55.5 万个单词或 250 万个 Unicode 字符；此前模型的 100 万令牌约可容纳 75 万个单词。20 万令牌约相当于 15 万个单词。
* **最大输出:** 同步 Messages API 的输出上限。在 Message Batches API 中，Claude Opus 5.5、Claude Opus 5、Claude Sonnet 5.5、Claude Sonnet 5、Claude Haiku 5.5、Claude Opus 4.8、Claude Opus 4.7、Claude Opus 4.6 和 Claude Sonnet 4.6 可通过 output-300k-2026-03-24 测试版请求头支持最多 30 万输出令牌。
* **每百万令牌价格:** 输入／输出的每百万令牌基础价格。Batch API 请求享受五折优惠；提示缓存读取费用为基础输入价格的 10%（Claude Fable 5.2、Claude Mythos 5.2、Claude Fable 5.1 和 Claude Mythos 5.1 为 2.5%，Claude Opus 5.5 和 Claude Sonnet 5.5 为 5%）。完整列表请参阅定价页。
* **延迟:** 模型概览中公布的相对延迟。实际延迟取决于提示长度、输出长度和思考强度。
* **思考:** 自适应思考由模型决定思考量，并通过 effort 调节。扩展思考是早期模型上手动设置 budget\_tokens 的模式。
* **默认 effort:** Claude API 中 effort 参数的默认值。未列出默认值的模型不支持此参数。
* **知识截止日期:** 可靠知识截止日期，即模型知识覆盖最广泛、最可靠的截止日期。

## 须知

* 自适应思考始终开启，无法关闭。请使用 [effort 参数](/docs/build-with-claude/effort)控制思考深度。
* 强制工具使用（`tool_choice` 类型 `any` 和 `tool`）会返回 400 错误。请参阅[思考与工具选择](/docs/models/fable-5-2/whats-new-fable-5-2#thinking-and-tool-choice)。
* 请省略 `temperature`、`top_p` 和 `top_k`。有关会返回 400 错误的值，请参阅[采样参数](/docs/build-with-claude/thinking#sampling-parameters)。
* Claude Fable 5.2 要求 30 天数据保留，除非获得 Anthropic 明确授权，否则无法在 “zero data retention”（零数据保留）下使用。请参阅[特定模型的数据保留要求](/docs/manage-claude/api-and-data-retention#model-specific-data-retention-requirements)。
* 使用 [Models API](/docs/api/models/list) 以编程方式查询限制和能力。

## Claude Fable 5.1 与 Claude Mythos 5.1

[Claude Mythos 5.1](/docs/models/mythos-5-1/overview) 提供相同的能力，但仅面向通过 Anthropic 验证计划（例如 [Cyber Verification Program](https://support.claude.com/en/articles/14604842)）验证的组织。它与 Claude Fable 5.1 共享相同的规格和定价。如需申请访问权限，请申请涵盖您用例的计划，或联系您的 Anthropic、AWS 或 Google Cloud 客户团队。

## 与当前模型阵容的对比

| 模型                                                                                  | 上下文 | 最大输出 | 每百万令牌价格       | 思考             | 默认 effort | 知识截止日期 |
| :------------------------------------------------------------------------------------- | :------ | :--------- | :----------------- | :------------------- | :------------- | :--------------- |
| [Claude Fable 5.2](/docs/models/fable-5-2/overview)   | 1M      | 128K       | $8 / $40           | 自适应（始终开启） | `high`         | 2026 年 6 月         |
| **Claude Fable 5.1** (本模型)                                                      | 1M      | 128K       | $10 / $50          | 自适应（始终开启） | `high`         | 2026 年 6 月         |
| [Claude Opus 5.5](/docs/models/opus-5-5/overview)     | 1M      | 128K       | $4 / $20           | 自适应（始终开启） | `medium`       | 2026 年 6 月         |
| [Claude Sonnet 5.5](/docs/models/sonnet-5-5/overview) | 1M      | 128K       | $2 / $10           | 自适应             | `high`         | 2026 年 6 月         |
| [Claude Haiku 5.5](/docs/models/haiku-5-5/overview)   | 1M      | 128K       | 起价 $0.10 / $0.50 | 自适应             | `medium`       | 2026 年 6 月         |

* **上下文:** 在当前分词器（随 Claude Opus 4.7 引入）中，100 万令牌约相当于 55.5 万个单词或 250 万个 Unicode 字符；此前模型的 100 万令牌约可容纳 75 万个单词。20 万令牌约相当于 15 万个单词。
* **最大输出:** 同步 Messages API 的输出上限。在 Message Batches API 中，Claude Opus 5.5、Claude Opus 5、Claude Sonnet 5.5、Claude Sonnet 5、Claude Haiku 5.5、Claude Opus 4.8、Claude Opus 4.7、Claude Opus 4.6 和 Claude Sonnet 4.6 可通过 output-300k-2026-03-24 测试版请求头支持最多 30 万输出令牌。
* **每百万令牌价格:** 输入／输出的每百万令牌基础价格。Batch API 请求享受五折优惠；提示缓存读取费用为基础输入价格的 10%（Claude Fable 5.2、Claude Mythos 5.2、Claude Fable 5.1 和 Claude Mythos 5.1 为 2.5%，Claude Opus 5.5 和 Claude Sonnet 5.5 为 5%）。完整列表请参阅定价页。
* **思考:** 自适应思考由模型决定思考量，并通过 effort 调节。扩展思考是早期模型上手动设置 budget\_tokens 的模式。
* **默认 effort:** Claude API 中 effort 参数的默认值。未列出默认值的模型不支持此参数。
* **知识截止日期:** 可靠知识截止日期，即模型知识覆盖最广泛、最可靠的截止日期。

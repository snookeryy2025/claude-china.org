## 概述

Claude Sonnet 5.5 提供了速度与智能的最佳组合。它专为日常编码、智能体和企业工作负载而构建，例如代码生成、数据分析、内容创作、视觉理解和智能体工具使用。

| [Claude Haiku 5.5](/docs/models/haiku-5-5/overview) | 1M      | 128K       | 起价 $0.10 / $0.50 | 最快  | 自适应             | `medium`       | 2026 年 6 月         |

* **上下文:** 在当前分词器（随 Claude Opus 4.7 引入）中，100 万令牌约相当于 55.5 万个单词或 250 万个 Unicode 字符；此前模型的 100 万令牌约可容纳 75 万个单词。20 万令牌约相当于 15 万个单词。
* **最大输出:** 同步 Messages API 的输出上限。在 Message Batches API 中，Claude Opus 5.5、Claude Opus 5、Claude Sonnet 5.5、Claude Sonnet 5、Claude Haiku 5.5、Claude Opus 4.8、Claude Opus 4.7、Claude Opus 4.6 和 Claude Sonnet 4.6 可通过 output-300k-2026-03-24 测试版请求头支持最多 30 万输出令牌。
* **每百万令牌价格:** 输入／输出的每百万令牌基础价格。Batch API 请求享受五折优惠；提示缓存读取费用为基础输入价格的 10%（Claude Fable 5.2、Claude Mythos 5.2、Claude Fable 5.1 和 Claude Mythos 5.1 为 2.5%，Claude Opus 5.5 和 Claude Sonnet 5.5 为 5%）。完整列表请参阅定价页。
* **延迟:** 模型概览中公布的相对延迟。实际延迟取决于提示长度、输出长度和思考强度。
* **思考:** 自适应思考由模型决定思考量，并通过 effort 调节。扩展思考是早期模型上手动设置 budget\_tokens 的模式。
* **默认 effort:** Claude API 中 effort 参数的默认值。未列出默认值的模型不支持此参数。
* **知识截止日期:** 可靠知识截止日期，即模型知识覆盖最广泛、最可靠的截止日期。

## 须知

* 自适应思考默认开启。最低的思考设置是 `between_tools`，它会关闭预先思考。该设置适用于 `high` “effort”（努力程度）或更低级别。请参阅 [Claude Sonnet 5.5 的新功能](/docs/models/sonnet-5-5/whats-new-sonnet-5-5#turn-off-up-front-thinking)。
* 设置 `temperature`、`top_p` 或 `top_k` 会返回 400 错误。
* 最小可缓存提示长度为 512 个令牌。请参阅[提示缓存](/docs/build-with-claude/prompt-caching#cache-limitations)。
* 在 [Message Batches API](/docs/build-with-claude/batch-processing#extended-output-beta) 上，Claude Sonnet 5.5 配合 `output-300k-2026-03-24` beta 标头最多支持 300k 个输出令牌。
* 使用 [Models API](/docs/api/models/list) 以编程方式查询限制和功能。
